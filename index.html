How to Connect Your Official Gmail & Google Sheet (2-Minute Setup)

100% Free Google API

By setting up a simple **Google Apps Script** inside a Google Sheet, you can send real emails directly from your `YOUR_NAME@gmail.com` account and record every pitch in your spreadsheet without paying for expensive third-party mail tools!

1

Create a Google Sheet

Open sheets.new in your browser and name it "Siddho CRM Outreach Logs". Add 5 headers in row 1: Timestamp | Email | Business Name | Template | Status.

2

Open Apps Script Editor

In your Google Sheet menu, click Extensions → Apps Script. A new code editor tab will open.

3

Paste the Backend Code (`Code.gs`)

Delete any existing code in the editor and copy-paste the exact code from our ready-made `Code.gs` script below:

Google Apps Script Backend (Code.gs) 
// Click copy button or view Code.gs file in project directory
4

Deploy as Web App

Click the blue Deploy → New deployment button at the top right of the Apps Script editor. Click the gear icon next to "Select type" and choose Web app.
• Set Description: Siddho CRM Email API
• Set Execute as: Me (your email)
• Set Who has access: Anyone (CRITICAL for dashboard communication)
Click Deploy and authorize permissions.

5

Paste Web App URL into This Dashboard

Copy the generated Web App URL (`https://script.google.com/macros/s/.../exec`) and paste it by clicking the "Configure Backend URL" button at the top of this dashboard!

Backend API Configuration
